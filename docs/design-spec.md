# UI 设计规范

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色 | `#4A90D9` | 按钮、标签、强调元素 |
| 主色浅 | `#E8F1FB` | 卡片背景、选中态背景 |
| 主色深 | `#3A7BC8` | 按钮按压态 |
| 文字主 | `#1A1A1A` | 标题、正文 |
| 文字次 | `#666666` | 辅助说明、日期 |
| 文字弱 | `#999999` | 占位符、禁用态 |
| 背景 | `#F5F7FA` | 页面底色 |
| 卡片 | `#FFFFFF` | 卡片、列表项背景 |
| 支出 | `#E85D75` | 支出金额、支出标签 |
| 收入 | `#4CAF50` | 收入金额、收入标签 |
| 分割线 | `#EEEEEE` | 列表分割、卡片边框 |
| 警告 | `#FF6B6B` | 超支提醒 |

## 字体层级

| 层级 | 大小 | 粗细 | 用途 |
|------|------|------|------|
| H1 | 24px | 700 | 页面主标题 |
| H2 | 18px | 600 | 卡片标题 |
| Body | 16px | 400 | 正文、输入框 |
| Small | 14px | 400 | 辅助文字 |
| Caption | 12px | 400 | 日期、标签 |
| Amount | 28px | 700 | 金额展示 |

## 间距系统（4px 基准）

| 名称 | 值 | 用途 |
|------|----|------|
| xs | 4px | 图标与文字间距 |
| sm | 8px | 标签内边距 |
| md | 12px | 列表项内边距 |
| lg | 16px | 卡片内边距 |
| xl | 20px | 页面水平边距 |
| xxl | 24px | 段落间距 |

## 触控规范

- 最小触控热区：44×44px
- 按钮最小高度：44px
- 列表项最小高度：56px
- 输入框高度：48px
- 圆角：卡片 12px，按钮 8px，输入框 8px

## 阴影

- 卡片：`0 2px 8px rgba(0,0,0,0.08)`
- 按钮：`0 2px 4px rgba(74,144,217,0.3)`
- 底部导航：`0 -2px 8px rgba(0,0,0,0.06)`
