# 需求规格说明

## 功能需求

### F1 自然语言记账
- 用户在输入框用自然语言描述消费/收入
- 系统自动解析：金额、类别、时间、收支类型、备注
- 解析结果展示在确认面板，用户可手动修改任意字段
- 确认后保存记录

### F2 账单记录管理
- 按日期倒序展示所有账单
- 支持关键词搜索（匹配备注和类别）
- 支持筛选：日期范围、类别、收支类型
- 支持编辑和删除记录
- 删除前需确认

### F3 月度报表
- 当月分类支出饼图
- 近6个月收支趋势柱状图
- 当月收支汇总卡片（总收入 / 总支出 / 结余）

### F4 预算管理
- 用户可设置月度预算金额
- 首页展示当月消费进度条
- 剩余额度实时显示
- 超出预算时红色醒目提醒

### F5 PWA 离线支持
- 可安装到手机桌面
- 离线可正常打开已缓存的页面
- 启动画面和应用图标

## 非功能需求

- 纯本地存储，无需网络（记账、查看均离线可用）
- 移动端触控优先，按钮热区 ≥ 44px
- 输入响应 < 100ms（本地解析）
- PWA Lighthouse 评分 ≥ 80

## 用户场景

1. **日常记账**：打开 App → 输入"午饭花了30" → 确认解析 → 保存
2. **查看账单**：打开 App → 账单列表 → 搜索/筛选 → 找到目标记录
3. **查看报表**：打开 App → 报表页 → 查看当月饼图和近期趋势
4. **设置预算**：首页 → 设置月度预算 → 实时查看消费进度
