# 自然语言解析引擎

## 设计原则
- 纯本地规则匹配，零网络依赖
- 解析结果可被用户修正
- 容错设计：部分解析失败时保留已识别字段

## 解析流程

```
输入文本
  ↓
1. 时间提取 → 识别"今天/昨天/前天/周X/XX号"等 → 计算具体日期
  ↓
2. 金额提取 → 正则匹配数字 + 单位词 → 提取数值
  ↓
3. 收支判断 → 关键词匹配"花/买/付/消费"→支出，"赚/收入/到账"→收入
  ↓
4. 类别推断 → 基于关键词映射表匹配分类
  ↓
5. 备注生成 → 去除时间/金额/收支词后，剩余文本作为备注
  ↓
输出: { amount, category, date, type, note }
```

## 1. 时间提取

| 输入 | 解析结果 |
|------|----------|
| 今天 | 当天日期 |
| 昨天 | 当天 - 1 |
| 前天 | 当天 - 2 |
| 大前天 | 当天 - 3 |
| 上周X | 上周对应星期 |
| 周X / 星期X | 本周对应星期 |
| X号 / X日 | 当月 X 日 |
| X月X号 / X月X日 | 对应日期 |
| 无时间词 | 默认为当天 |

正则：`/(\d{1,2})月(\d{1,2})[号日]|(\d{1,2})[号日]|上周([一二三四五六日])|周([一二三四五六日])|星期([一二三四五六日])|今天|昨天|前天|大前天/`

## 2. 金额提取

正则：`/(\d+(?:\.\d{1,2})?)\s*(块|元|¥|块钱|元钱|rmb|RMB)?/i`

- 支持整数和小数（最多两位小数）
- 多金额时取最大或第一个
- 无金额时标记待填写

## 3. 收支判断

**支出词**：花、买、付、消费、交、充、还、扣、转账出去
**收入词**：赚、收入、到账、发工资、发薪、收、进账、退款、报销

- 同时出现支出词和收入词时，以先出现的为准
- 无明确词时默认支出

## 4. 类别推断

详见 `docs/category-system.md` 关键词映射表。

匹配策略：
1. 遍历所有分类关键词，找到匹配项
2. 多个匹配时，选择关键词最长匹配（更精确）
3. 无匹配时默认"其他"

## 5. 解析结果接口

```typescript
interface ParseResult {
  amount: number | null;
  category: string;
  date: Date;
  type: 'expense' | 'income';
  note: string;
  raw: string;        // 原始输入
  confidence: {       // 各字段置信度 0-1
    amount: number;
    category: number;
    date: number;
    type: number;
  };
}
```
